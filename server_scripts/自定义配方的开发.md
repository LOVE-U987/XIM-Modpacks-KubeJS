# 自定义配方的开发

本文档记录了在XIM1.16.0.2-Alpha版本中添加的自定义合成配方的开发过程和详细说明。

## 配方概述

在这个版本中，我们添加了7个自定义合成配方，主要利用了`alltheores:fluorite`（萤石）作为基础材料，实现了一些特殊的物品合成。这些配方已经保存在`server_scripts/custom_recipes.js`文件中。

## 已添加的配方

### 1. 萤石合成钻石
- **输入**：9个萤石（3x3格子填满）
- **输出**：1个钻石
- **用途**：提供了一种非传统的钻石获取方式

```javascript
// 代码实现
event.shaped(
    Item.of('minecraft:diamond'),
    [
        'AAA',
        'AAA',
        'AAA'
    ],
    {
        A: 'alltheores:fluorite'
    }
)
```

### 2. 萤石和铁锭合成更多铁锭
- **输入**：中心1个铁锭，周围4个萤石
- **输出**：2个铁锭
- **用途**：提供铁锭的增值合成方式

```javascript
// 代码实现
event.shaped(
    Item.of('minecraft:iron_ingot', 2),
    [
        ' A ',
        'ABA',
        ' A '
    ],
    {
        B: 'minecraft:iron_ingot',
        A: 'alltheores:fluorite'
    }
)
```

## 使用方法

这些配方会在服务器启动时自动加载。玩家可以在游戏中通过工作台按照上述配方进行合成。

## 后续开发计划

1. 添加更多基于不同材料的自定义配方
2. 考虑平衡调整现有的配方
3. 添加一些特殊的合成条件

## 注意事项

- 确保`alltheores`模组已正确安装，否则萤石相关的配方将无法正常工作
- 这些配方可能会影响游戏的平衡性，请根据实际情况进行调整
- 如有任何问题，请查看`报错日志`文件夹中的错误信息
