# EMI错误抑制脚本说明

## 版本兼容性

本脚本已针对 **KubeJS 2101.7.1** 版本（适配Minecraft 1.21.1 NeoForge）进行了优化和更新。

## 概述

本脚本`suppress_emi_errors.js`用于抑制Minecraft中EMI（物品管理器）模组的NBT解析错误。这些错误通常不会影响游戏功能，但会在控制台中显示，可能造成不必要的困扰。

## 问题描述

在游戏启动或资源重载时，您可能会看到类似以下的错误信息：
```
[ERROR] [EMI/]: Error parsing NBT in deserialized stack
java.util.NoSuchElementException: No value present
```

这些错误通常是由于EMI尝试加载损坏或无效的物品数据（特别是侧边栏数据）导致的，但不会影响您已加载的脚本或游戏功能。

## 解决方案

本脚本通过以下方式解决问题：

1. **全局错误捕获**：设置自定义的未捕获异常处理器，专门识别并抑制EMI的NBT解析错误
2. **选择性抑制**：只抑制EMI的NBT解析错误，其他类型的错误仍会正常显示
3. **不影响功能**：脚本仅抑制错误信息的显示，不会影响游戏或EMI的正常功能

## 脚本工作原理

脚本利用KubeJS的客户端事件系统实现错误抑制：

1. 在`ClientEvents.loggedIn`事件中初始化错误抑制功能
2. 在`ClientEvents.assets`事件（资源重载阶段）中设置全局错误处理器
3. 在`ClientEvents.postInit`事件中应用额外的错误抑制措施
4. 当检测到EMI的NBT解析错误时，脚本会捕获这些错误并阻止它们显示在控制台中
5. 对于其他类型的错误，保持原始的错误处理机制不变

## 使用方法

1. 确保脚本`suppress_emi_errors.js`位于`kubejs/client_scripts/`目录下
2. 启动游戏或使用`F3+T`重新加载客户端资源
3. 脚本会自动运行并抑制EMI的NBT解析错误

## 注意事项

- 此脚本仅抑制错误信息的显示，不会修复EMI模组的底层问题
- 如果您希望完全解决这些错误，建议按照以下步骤操作：
  1. 在游戏中按E打开背包界面
  2. 点击EMI的设置按钮（齿轮图标）
  3. 找到并点击"重置所有设置"或"清除侧边栏"选项
  4. 重启游戏
- 该脚本在每次游戏启动时会自动运行，无需手动操作

## 查看脚本运行状态

脚本运行时会在日志中输出以下信息：
- 加载时：`[EMI错误抑制] 开始加载EMI错误抑制脚本...`
- 客户端登录时：`[EMI错误抑制] 客户端已加载，错误抑制功能已启动`
- 资源重载时：`[EMI错误抑制] 准备在资源重载期间抑制错误...`
- 成功设置处理器：`[EMI错误抑制] 全局错误处理器已成功设置`

如果需要查看这些日志，可以在游戏中按F3+L打开调试日志，或查看`logs/kubejs/`目录下的客户端日志文件。
